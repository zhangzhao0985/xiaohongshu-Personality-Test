# 你的什么欲望最强 · 专属欲望档案

一个给小红书用的「人格 / 欲望」付费测试单页网站。买家在小红书下单 → 拿到订单编号 → 在网页里填编号 → 解锁完整测试结果。

> 小昭你好 👋 这份说明就是写给你的。**真正需要你改的只有一个文件里的一小块（`app.js` 顶部的 `CONFIG`）**，其它都不用动。

---

## 🌸 它长什么样 / 用户怎么用

1. **首页**：主题「你的什么欲望最强？」，价值点 + 价格（原价 ¥3，折后 ¥1.49），一个「开始测试」按钮。
2. 进首页会自动弹出**小昭的「主题抽奖通知」**（你写的那段话），告诉用户怎么下单、怎么拿订单编号。
3. **20 道情境题**：凭直觉选最像自己的那个，带进度条，约 2 分钟。
4. **结果页**：
   - **免费可见**：先揭晓「你的最强欲望是 XX」+ 一句钩子。
   - **付费解锁**：完整《欲望档案》（欲望光谱图、主导欲望详解、隐藏面、想我指数、小昭寄语）默认是**模糊锁定**的。
5. 用户输入**订单编号**：
   - 编号正确 → 弹出「解锁成功」→ 完整档案揭晓。
   - 编号错误 / 没有编号 → 再次弹出小昭的购买引导弹窗。

## ⚙️ 你需要改的地方（只有这一块）

打开 **`app.js`**，最顶部有一个 `CONFIG`。按注释改这几项就行：

```js
const CONFIG = {
  // 1. 你的小红书店铺名
  SHOP_NAME: "待补充",      // 改成你的店铺名，例如 "小昭的杂货铺"
  SHOP_URL: "",             // 可留空；填了你的店铺链接，弹窗里会多出「前往店铺 →」按钮

  // 2. 价格
  PRICE_NOW: "1.49",
  PRICE_OLD: "¥3",

  // 3. 有效订单编号 / 解锁码（最关键）
  VALID_ORDER_CODES: [
    "TEST-1314",   // ← 演示码，上线前请删掉
    // "把买家下单后的真实订单编号一行一个加在这里",
  ],

  // 4. 进阶（一般不用动）
  ACCEPT_ANY_LONG_NUMBER: false, // true = 任何 8 位以上纯数字都放行（更省事但几乎不设防）
  CONTROL_THRESHOLD: 4,          // 触发隐藏维度「控制欲」需要的选择次数（共 6 次机会）
};
```

### 订单编号怎么运作？（重要）
- 买家在小红书下单后会拿到一个**订单编号**。你把这个编号**加进 `VALID_ORDER_CODES` 列表**（一行一个），买家输入它就能解锁。
- 也可以不用真实订单号，而是**自己发“解锁码”**：比如每个买家你统一发一个 `ZHAO-0001`、`ZHAO-0002`…，把这些码填进列表即可。
- 校验**忽略大小写和首尾空格**（`test-1314` 和 `TEST-1314` 等价）。
- **上线前一定要删掉演示码 `TEST-1314`**，否则任何人都能用它白嫖。

> ⚠️ 说明：这是「前端码表」方案，**零成本、纯静态、好部署**，适合小规模、靠信任。它的局限是：技术上能被绕过，且同一个编号能在多台设备重复使用。如果以后量大了、想要“防绕过 / 防重复使用 / 自动对接发货”，可以升级成带后端的版本（找我加即可）。

## 🚀 怎么免费上线（拿到一个网址）

这是个纯静态网站（`index.html` + `styles.css` + `app.js`），任何静态托管都能放。最省事的两种：

### 方式一：Vercel（推荐，最快）
1. 把这个仓库导入 [vercel.com](https://vercel.com)（用 GitHub 登录）。
2. 一路默认，点 Deploy。
3. 几十秒后会得到一个网址，例如 `https://xxx.vercel.app`，这就是你要放到小红书的链接。

### 方式二：GitHub Pages
1. 仓库 **Settings → Pages**。
2. Source 选 `Deploy from a branch`，分支选你的主分支、目录 `/ (root)`。
3. 保存后等一两分钟，会给出 `https://用户名.github.io/仓库名/` 的网址。

> 改完 `CONFIG` 记得重新提交，托管平台会自动更新。

## ✍️ 想改测试题 / 文案？

都在 `app.js` 里，结构很清楚：

| 想改的东西 | 在 `app.js` 里找 |
|---|---|
| 20 道题目和选项 | `QUESTIONS` |
| 各欲望的结果文案（描述、标签、想我指数文案、寄语） | `PROFILES` |
| 首页 4 个价值点 | `VALUE_POINTS` |
| 小昭寄语的统一结尾 | `ZHAO_TAIL` |
| 弹窗里那段“主题抽奖通知”的话 | `index.html` 里 `id="shopModal"` 那一段 |

> 小贴士：每道题的选项里，`k` 是它对应的欲望维度（`love` 爱欲 / `thing` 物欲 / `food` 食欲 / `own` 占有欲 / `control` 控制欲）。隐藏维度 `control` 只出现在其中 6 道题里。改题时，尽量让 4 个核心维度在题目中出现的次数差不多，结果才准。
